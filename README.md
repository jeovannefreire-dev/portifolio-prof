# Portfólio dos Alunos

## Como executar
1. Abra esta pasta no Visual Studio Code.
2. Abra o arquivo `index.html`.
3. Use o Live Server para visualizar o site no navegador.

## O que o aluno deve editar
- `SEU NOME`
- texto da seção Sobre mim
- habilidades
- projetos
- formação
- e-mail, LinkedIn e GitHub
- área `SUA FOTO`

## Estrutura
- `index.html` — conteúdo
- `style.css` — aparência
- `script.js` — interações
- `images/` — imagens do aluno
